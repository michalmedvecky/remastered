# V1.07 fidelity implementation, release 0.6

Release 0.6 integrates the user-approved [painted HD artwork](HD-GRAPHICS.md) for all known world buildings, units and terrain. New whole RGBA drawings follow actual native draw commands and preserve logical geometry. Original mode remains available. Historical 0.4 material and 0.5 xBR captures remain labeled separately; current evidence is under `fidelity/painted/`. Native simulation, source/WASM and original DOS comparison results are unchanged.

The default browser game now executes the complete recovered C core, replacing the first release’s approximate JavaScript terrain, combat and object state machines. The original UNIT, BUILD and TEAM EMC programs dispatch into native C callbacks operating on the engine’s own object pools, script state, map and game clocks. Native menus, campaign progression, WSA cutscenes and IFF save/load routines are retained. The browser executes the rebuilt C engine. The supplied DOS EXE was also executed in the separately authorized, bounded DOSBox-X comparisons on disposable copies described below.

The requested five areas have native implementations and selected original-runtime comparisons. It is not proof that all native behavior has been recovered without differences. Observed binary facts, reconstructed source behavior, tests of newly compiled code and unobserved original runtime behavior remain distinct below.

## Browser hardware layer

The core is compiled with Emscripten 7.0.0, SDL2 2.32.10 and Asyncify. Its cooperative wait yields to the browser; native 120/60 Hz callback intervals remain intact. A monotonic foreground clock excludes hidden-tab time, and both music and sampled audio pause in hidden tabs. Video converts the full native indexed framebuffer before presenting, because WebGL backbuffers and locked textures cannot be assumed to retain partial dirty rectangles. Original mode stretches 320×200 to the original 4:3 presentation with nearest-neighbor sampling. Painted HD uses new world artwork at4× with square presentation pixels; original menus and movie art remain native. Input still maps to the same logical coordinates.

Keyboard events are scoped to the canvas so help, save import and volume controls do not issue game commands. Browser help/save dialogs pause the clock and audio while open. The browser launch checkbox can skip the initial introduction once; the original Replay Introduction command remains available. Native personal files live in an automatically persisted IDBFS mount at `/save`. The original menu enumerates contiguous `_saveNNN.dat` names, so imports append into the first free slot and preserve existing saves. Original `SAVE000.DAT` and browser `_save000.dat` envelopes are accepted; unrelated or truncated IFF files are rejected. Exported saves use the recovered native IFF format, including OpenDUNE’s ODUN extension. An exported port save was loaded and re-saved by the original DOS game. Both that DOS re-save and a clean original save load in the rebuilt native engine; independently parsed unit/building core fields agree. These named files establish cross-loading for those cases, not universal interchange.

## Remaining uncertainty

* Real allocator snapshots now cover the three named seeds, including observed out-of-map neighbor classes. Other adjacent-memory states and object-overlaid complete mission maps remain outside those assertions; the safe terrain model stays explicit.
* The archive lacks `OK.VOC`. Three music mappings point at absent ADL entries and intentionally produce silence.
* The bounded runs do not cover every campaign, weapon interaction or full credits cycle. Recovered code, original-instruction fixture results and full-game observations remain separate evidence categories.
* DOSBox-X VGA/OPL observations are the runtime reference. Physical AdLib output, browser resampling, MT-32/CM-32L synthesis and exact browser/DOS wall-clock equality are not claimed. Headless native scene timing advances on cooperative waits and excludes CPU/disk costs.
* The tested saves cross-load successfully. Other game versions and unusual save states have not all been tested.
