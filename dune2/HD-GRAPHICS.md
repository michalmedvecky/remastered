# Approved painted HD — release 0.8.0

The user approved the whole-object art pilot and requested all buildings, units and terrain in that style. The active game now uses complete painted RGBA artwork at 1280×800. It does not use the rejected generic material overlay or xBR smoothing. Original mode remains available without restarting.

## Complete corresponding-source downloads

The [source index](dist/native/source.html) links the main `source.tar.gz` plus every content-addressed artwork volume. Each artwork volume is at most48MiB uncompressed. The main archive retains code, licenses, prompts and manifests; volumes carry large generated artwork, original decoded reference inputs and matching runtime PNGs. Extract every archive into the same empty directory. `SOURCE-MANIFEST.json` maps each exact source file to its volume, byte count, mode and SHA256. `SOURCE-PACKAGE.json` records all published archive hashes and sizes.

`python3 tools/verify-source-package.py` reconstructs the complete source tree from all volumes in a temporary directory and compares every current corresponding-source byte. It rejects missing/extra files, unsafe paths, links, duplicate members, changed hashes and oversized art volumes. Original ZIP/EXE/COM/PAK files are excluded. The retained SDL dependency is repackaged as full matching source in deterministic tar.gz form, with its two safe source links materialized. Original game data remains an owner-supplied native-build input.
