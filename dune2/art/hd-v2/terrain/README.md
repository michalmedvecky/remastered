# Painted semantic terrain bank

This bank covers all135 nonbuilding ICON IDs: sentinel0; rock/sand craters1–12; wrecks13–18; fallen infantry/remains19–24; tracks25–32; fog108–123; partial slab124, rubble125, concrete126; all81 native landscape transition IDs127–207; spice blooms208–209. Walls33–107 and building tiles210–388 belong to the building bank. Shared slab125/rock143 used by construction animations remain canonical terrain IDs when standalone.

`raw/` retains three built-in imagegen outputs and exact prompts. `PROVENANCE.json` records input roles, hashes and the source alpha matte limitation. `node tools/build-painted-terrain.mjs` from `dune2/` emits the content-addressed surface/mask/overlay PNGs and `dist/painted/terrain.json`. It reads the hash-bound original `dist/painted/native.json`; no DOS code is executed.

The renderer paints continuous RGBA semantic planes with world-coordinate UVs. It never resets a texture at each16-pixel native tile, and never tints a source pixel with generated microtexture. Original ICON identities select class masks: sand, dune, basalt, mountain, spice, dense spice, concrete and rubble. Original palette/code regions describe topology, with declared boundary-only smoothing. Both phases also gate every cell on the native isUnveiled word, even when its overlay ID is zero; false visibility paints black after buildings as well. Exact original descriptors are separately retained for the root compositor’s native pixel prediction. Native fog alpha is unchanged and nearest-expanded; no procedural noise can reveal unknown ground.

`createPaintedTerrain({manifestURL})` returns `draw(ctx,frame,{scale:4,phase:'ground'|'overlay'|'both'})`, `descriptors`, `manifest` and `diagnostics()`. Root canvas coordinates are physical1280×800; the ground clip is960×640 at(0,160). Ground draws rock below unowned building/wall IDs; the root paints those objects between phases. Overlay draws new ground marks and native fog. The owning compositor gates palette fades/modals and keeps original input/gameplay authoritative.

All ten surface planes have matched repeat edges at512 painted pixels, covering128 native world pixels. Different mask cells sample the same world UV instead of introducing16px seams. A fixed cache retains at most ten class masks; it rebuilds only when camera or native tile records change. The original full surface atlas is released after semantic planes are extracted.

Five tests independently decode every owned original ICN index/mask/palette, verify389-way disjoint ownership, exact fog and full-class endpoints, generated hashes/transparent extents, edge joins and tile/camera UV continuity. Root browser acceptance remains separate. Cosmetic state variants are derived from six new painted archetypes; they are not claims of exact original corpse/crater artwork or new gameplay recovery.
